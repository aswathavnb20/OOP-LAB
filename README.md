# OOP LAB

**Owner: aswathavnb20**

Six C++17 experiments with source code and program outputs.

| Experiment | Topic |
| --- | --- |
| 01 | Classes, constructors, destructors and object lifetime |
| 02 | Abstract classes and runtime polymorphism |
| 03 | Matrix addition and multiplication using operator overloading |
| 04 | Template stacks and queues with STL comparison |
| 05 | Student grade analysis using STL algorithms |
| 06 | RAII, unique ownership, shared ownership and weak pointers |

Each experiment folder contains its C++ source, captured output text and an output image. Benchmark timings vary between runs.

## Build and run

With a C++17 compiler, for example:

```sh
g++ -std=c++17 -Wall -Wextra -pedantic "EXPERIMENT 01/Experiment1.cpp" -o experiment1
./experiment1
```

The Actions workflow builds and runs all six programs.
